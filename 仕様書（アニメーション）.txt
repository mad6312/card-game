機能拡張：「ダイヤの剣」へのカットインアニメーション実装
「グレネード」で実装したスプラッシュ仕様および広域爆発演出を踏襲し、「ダイヤの剣」のカットインアニメーション実装をお願いいたします。
対象カード：「ダイヤの剣」
「ダイヤの剣」固有の重要ポイント：
Ⅰ. 使用者は演出に登場しない：画面左側の攻撃者（自分）は原則登場せず、対象プレイヤー群のみが画面中央に配置されます（※ただし、自分がスプラッシュ対象に含まれる場合は画面内に登場します）。
Ⅱ. 天空からの刺突演出：突進や手榴弾の投擲ではなく、天空から勢いよく地上へダイヤの剣（画像添付）が突き刺さり爆発する演出となります。
Ⅲ. 全対象の同時アクション：「グレネード」同様、全対象（スプラッシュ・自分を含む）が**1度（同時）にアクション（吹き飛び・回避・耐え）**を起こします。
1. 画面構成および配置ルール
・着弾・中心座標：本ターゲットの「中心位置」を基準とします。
・整列ルール（スプラッシュ対象の数に応じた配置）：
スプラッシュ 1名：本ターゲットの「右隣」
スプラッシュ 2名：本ターゲットを挟む「左右」
スプラッシュ 3名：左から [対象A] [対象B] [本ターゲット] [対象C] の順で配置
※自分が本ターゲットもしくはスプラッシュ対象に含まれている場合でも、全体の並び順ルールにそのまま従います。
2. アニメーション演出および判定仕様
吹き飛び方向（同時アクション）：
各配置位置に応じて、中央から放射状（左 / 左上 / 上 / 右上）へ同時に吹き飛びます。
防御カードおよび特殊状態の扱い：
「防御カード」セット時：「ダイヤの剣」は防御カードで防げない仕様のため、**「貫通！」ではなく通常通り「命中！」**と表示して吹き飛びます（※セットされている防御カード自体は従来通り破棄）。
「お守り小判 / お守り小判セット / お守り大判」保持時：これらによる回避が発生した対象は**「回避！」**表示とします。
「無敵 / ステロイド / 選択不可」時：吹き飛ぶことなくその場で微動だにせず、該当テキストを表示します（※防御カード破棄処理は通常通り適用）。
3. 代表的な演出分岐例
例1（直撃 ＋ スプラッシュ）：本ターゲットに命中し、スプラッシュ対象が1名 ➔ 剣の着弾・爆発と同時に2人が指定方向へ同時に吹き飛ぶ。
例2（本ターゲット回避 ＋ スプラッシュ被弾）：本ターゲットが「お守り小判」等で回避、スプラッシュ対象が被弾 ➔ 本ターゲットは「回避！」を表示、スプラッシュ対象は吹き飛ぶ。
例3（回避・無敵・命中が混在）：スプラッシュ対象に自分を含み3名存在。本ターゲットが「無敵/ステロイド/選択不可」、自分が「お守り小判」で回避、残りが被弾 ➔ 被弾した対象が吹き飛び（「命中！」）、自分は「回避！」、本ターゲットはその場で微動だにせず「無敵！」等のテキストを表示。
4. 実装にあたってのお願い（事前確認・モジュール分割）
・演出表現のディスカッション：
剣の落弾・爆発エフェクトの表現や「グレネード」との差異（使用者の非表示処理など）について疑問・懸念があれば、自己判断で進めず事前のディスカッションをお願いいたします。
・コード長・トークン上限について：
本演出の追加により出力トークン数が上限を超える懸念がある場合は、遠慮なくファイルのモジュール細分化をご相談ください。



機能拡張：「グレネード」への攻撃カットインアニメーション実装
既存のカットイン共通ロジックを踏襲しつつ、広範囲爆発およびスプラッシュ効果に対応した**「グレネード」の攻撃カットインアニメーション実装**をお願いいたします。
対象カード：「グレネード」
従来の演出との大きな違い：
Ⅰ. 突進ではなく、中央へ手榴弾（画像添付）を山なりに投げる広域爆発演出。
Ⅱ. 1人ずつ順番に処理するのではなく、全対象（スプラッシュ・自分を含む）が1度（同時）にアクションを起こす。
1. 画面構成および配置ルール
【パターンA：単体選択（自分との差が 0〜+5,000点）】
基本配置：左側＝自分（攻撃者）、右側＝本ターゲット（1名）
・スプラッシュ対象（本ターゲットと差1,000点以内）が存在する場合の整列：
・スプラッシュ対象 1名：本ターゲットの「右隣」に配置。
・スプラッシュ対象 2名：本ターゲットを挟むように「左右」に配置。
※「自分」がスプラッシュ対象に含まれる場合でも、自分の表示位置（左側）は固定。
【パターンB：グループ攻撃（自分との差が 0〜-5,000点全員）】
・既存の「木の盾」同様の配置決定ロジック（攻撃順・並び順）を適用。
※「自分」がスプラッシュに含まれる場合も自分の位置は変更なし。
2. アニメーション演出仕様
【基本挙動】
・着弾・爆発位置：誰が命中・回避したかに関わらず、画面右側の対象セット群の「中心座標」に固定。
・吹き飛び方向（同時アクション）：
対象群：配置位置に応じて扇状に吹き飛ぶ（左側へ配置＝左上 / 中央＝上 / 右側＝右上）。
自分：スプラッシュで巻き込まれた場合、常に**「左方向」**へ吹き飛ぶ。
・防御カード・特殊状態の扱い：
「貫通！」時は防御カードごと吹き飛ぶ。
「無敵」「ステロイド」「選択不可」のプレイヤーは吹き飛ぶことなく微動だにせず、該当テキストを表示（※ただし、セットされている防御カード自体は従来通り破棄される仕様は維持）。
【スプラッシュ判定のルール】
スプラッシュ（巻き込まれ）側には**「回避」および「貫通」判定は存在しません**（命中して吹き飛ぶか、無敵等の状態で耐えるかの2通り）。
3. 代表的な演出分岐例（パターンB・複数人時）
例1（直撃+スプラッシュ）：先頭に命中し、2番目がスプラッシュ対象の場合 ➔ 爆発と同時に2人が指定方向（左上・上など）へ同時に吹き飛ぶ。
例2（回避からのスプラッシュ命中）：先頭は回避、2番目に命中し、1番目が2番目のスプラッシュ範囲内の場合 ➔ 1番目と2番目が同時に吹き飛ぶ（3番目は待機）。
例3（自分と相手の無敵耐え）：3番目に命中し、先頭・2番目・自分がスプラッシュ対象。ただし自分と先頭が「無敵/ステロイド/選択不可」の場合 ➔ 2番目・3番目のみが吹き飛び、自分と先頭はその場で「無敵！」等のテキストを表示して微動だにしない。
4. 実装にあたってのお願い（事前確認・モジュール分割）
・演出表現のディスカッション：
グレネードの着弾・爆発エフェクト表現や、多岐にわたる同時アクション処理について疑問・懸念があれば、自己判断で進めず事前にご相談ください。
・コード長・トークン上限について：
スプラッシュ処理や同時アニメーションの追加によりコード長が出力トークン数上限を超えそうな場合は、遠慮なくファイルのモジュール細分化をご相談ください。



機能拡張：「木の盾セット」への複数回攻撃カットインアニメーション実装
「木の盾」等のカットインアニメーションの共通ロジックを踏襲し、「複数回攻撃（連続攻撃）」に対応したカットイン演出を「木の盾セット」へ実装していただくようお願いいたします。
まずは**「木の盾セット」で先行実装**を行い、挙動確認後に他のセット系カード（「木の剣セット」「青銅の盾セット」）へ横展開する予定です。
対象カード：「木の盾セット」
基本演出：「木の盾」のカットイン処理（突進 ➔ 命中/回避/防御/無敵の分岐）をベースとします。
ループ制御：2回以上の攻撃回数が指定された場合、基本アニメーションを下記の【終了条件】を満たすまで繰り返し再生してください。
1. アニメーション処理の終了（中断）条件
以下のいずれかを満たした時点で、**ループ・攻撃処理を即座に終了（中断）**してください。
Ⅰ. 指定した攻撃回数（またはカードの残り使用回数）をすべて消化した場合
Ⅱ. 攻撃対象となるプレイヤーが全員いなくなった場合
Ⅲ. 防御カード以外（「無敵状態」や「ステロイド状態」等）で攻撃が無効化・弾かれた場合
※「回避」などで全員に攻撃が外れた場合であっても、攻撃自体は実行されたものとして指定回数は消費されます。
2. 実装にあたってのお願い（事前確認・モジュール分割）
・ループ制御および疑問・懸念点について：
複数回攻撃のループ処理や終了条件の判定タイミング（タイマー処理含む）で迷う点があれば、自己判断で進めず事前のディスカッションをお願いいたします。
・コード長・トークン上限について：
本演出の実装により出力トークン数が上限を超える懸念がある場合は、遠慮なくファイルのモジュール細分化をご相談ください。



機能拡張：「ショットガン」への攻撃カットインアニメーション実装
「木の盾」「木の剣」「青銅の盾」で実装したカットインアニメーションの共通ロジックを踏襲しつつ、演出を銃撃仕様に変更した**「ショットガン」の攻撃カットインアニメーション実装**をお願いいたします。
対象カード：「ショットガン」
・基本的な挙動：既存のカットイン（突進）の共通処理をベースとしますが、攻撃アニメーションを「突進」から**「銃弾の発射・直進」**に変更します。
1. 画面構成（左右の配置）
左側（攻撃側）：[プレイヤー名 + アバター画像 + 「ショットガン」カードイラスト] の1セット
右側（対象側）：[プレイヤー名 + アバター画像] の1セット（※対象が複数の場合は判定順に横並び整列）
2. アニメーション基本演出（単体対象時）
攻撃側セットから右側の対象へ向かって「銃弾」が発射・直進し、判定結果に応じて演出が分岐します。※「銃弾」の表現（エフェクトや描画方法）については、実装前にご相談・ご提案いただけますと幸いです。
判定結果｜対象側の挙動演出｜表示テキスト
命中｜対象セットが銃弾を受けて画面外へ吹き飛ぶ｜「命中！」
回避｜対象セットが銃弾をサッと回避する｜「回避！」
防御（貫通）｜対象がセットしていた防御カードイラストが出現するが、防御カードごと打ち抜かれて画面外へ吹き飛ぶ｜「貫通！」
無敵状態/ステロイド状態による無効化｜対象セットが銃弾を受けても微動だにせず、銃弾を弾き返す｜「無敵！」 / 「ステロイド！」
3. 複数対象時のシームレス演出
対象全員が右側に横一列で整列し、発射された銃弾が左から順に直進します。判定処理で「回避」された場合でも弾は止まらず、次の対象へシームレスに直進を続行します。
・例（回避 ➔ 命中）：1人目がサッと回避（「回避！」） ➔ そのまま銃弾が直進し、2人目を吹き飛ばす（「命中！」）。3人目以降は動かない。
・例（回避 ➔ 防御貫通）：1人目がサッと回避（「回避！」） ➔ そのまま銃弾が直進し、2人目の防御カードごと打ち抜いて吹き飛ばす（「貫通！」）。3人目以降は動かない。
・例（全員回避）：1人目（回避！） ➔ 2人目（回避！） ➔ 3人目（回避！）と順に回避される。
・例（回避 ➔ 無敵/ステロイドで停止）：1人目が回避（「回避！」） ➔ 2人目の無敵/ステロイドで銃弾が弾き返される（「無敵！」/「ステロイド！」）。ここでアニメーション終了。
4. 実装にあたってのお願い（事前確認・モジュール分割）
・銃弾の表現および疑問・懸念点について：銃弾のエフェクト表現やタイマー処理（Delayなど）で迷う点があれば、自己判断で進めず事前のディスカッションをお願いいたします。
